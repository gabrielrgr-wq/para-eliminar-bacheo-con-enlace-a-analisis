# Reportes Bacheo Vial

Sistema de gestión y publicación de reportes para obras de bacheo vial.

## Archivos del Proyecto
- `index.html`: Página principal con acceso al informe PDF.
- `styles.css`: Hojas de estilo del sistema.

## Despliegue en GitHub Pages
1. Sube estos archivos al repositorio de GitHub.
2. Ve a **Settings** > **Pages**.
3. Selecciona la rama `main` (o `master`) y la carpeta raíz `/root`.
4. Guarda los cambios para publicar la aplicación.
